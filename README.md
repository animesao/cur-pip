# Cursor Installation Script for Arch Linux

This repository contains a shell script to automate the installation of Python and Cursor IDE on Arch Linux systems.

## Features

- Automatic system update
- Python and pip installation
- Cursor IDE installation via AUR
- Automatic dependency management
- Installation verification

## Prerequisites

- Arch Linux operating system
- Sudo privileges
- Internet connection

## Installation

1. Clone this repository:
```bash
git clone https://github.com/animesao/cur-pip.git
cd cursor-installer
```

2. Make the script executable:
```bash
chmod +x install_cursor.sh
```

3. Run the installation script:
```bash
./install_cursor.sh
```

## What's Included

- Python 3
- pip (Python package manager)
- Cursor IDE
- Required dependencies

## Usage

After installation, you can start Cursor by:
- Running `cursor` in your terminal
- Finding it in your applications menu

- Установка Python и pip
- Установка IDE Cursor через AUR
- Автоматическое управление зависимостями
- Проверка установки

## Требования

- Операционная система Arch Linux
- Права sudo
- Подключение к интернету

1. Клонируйте этот репозиторий:
```bash
git clone https://github.com/animesao/cur-pip.git
```

```bash
chmod +x install_cursor.sh
```

3. Запустите скрипт установки:
